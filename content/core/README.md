# Core prototype content

Built-in, schema-validated definitions for the first vertical slice belong
here: one original character, one fixed-duration job, and one basic room with
minimal furniture. Broader careers and general mod content are out of scope.

`characters/prototype-cat/idle.png` is the original four-frame horizontal sprite
sheet used by the first window artifact. The current renderer intentionally
shows only its first frame and stops the PixiJS ticker after rendering.
